About Technology.

Technology at Huge is powered by a global practice of creative technologists—spanning Engineers, QA specialists, Business Analysts, Data Scientists, and ML Architects—we look beyond standard patterns to build resilient, enterprise-grade systems. We combine deep engineering rigor with innovation at the edge of agentic AI, modern data stacks, and cloud infrastructure. We don't wait for industry standards to set themselves; we engineer the intelligent systems that turn audacious strategic vision into production-ready reality.

The role.

Huge is looking for a Senior Software Engineer who loves building scalable distributed platforms. You will join a team of skilled engineers working on microservices, event integration patterns and data orchestration across hybrid cloud and on-premise environments. The projects are diverse, the clients are global and the work ships.

What you'll be doing.

  • Build high-throughput services with .NET 8+, C# and ASP.NET Core Minimal APIs across a distributed microservices architecture designed for mobile clients.
  • Design and implement scalable, asynchronous pipelines using message-bus patterns and distributed pub/sub frameworks to move real-time data between decoupled services.
  • Architect and own secure integration endpoints, including webhooks, event ingestion pipelines and third-party data feeds.
  • Shape data strategy across modern cloud storage and on-premise databases. You will own data modeling, query optimization, synchronization patterns and data integrity across NoSQL and SQL platforms.
  • Build and deploy in containerized environments such as Azure Container Apps and Kubernetes. Treat infrastructure as code as a core part of development and use application performance monitoring (APM) to keep services healthy and fast.
  • Spot architectural roadblocks and capability gaps in the hybrid ecosystem early. Offer alternatives such as caching strategies or API gateway optimizations to keep projects on schedule.
  • Partner with Strategy, Creative and Client leads to turn complex business requirements into clear, executable technical solutions for mobile apps.
  • Mentor the engineering team and set the standard for backend and platform best practices.
  • Stay current on the .NET and cloud-native ecosystem and advocate for tools and frameworks that improve system quality, scale and developer productivity.

What we'd like to see.

  • 5+ years of hands-on experience with C#, .NET (Core/.NET 8+) and ASP.NET Core, building backend and distributed systems for high-concurrency applications.
  • Proven experience designing decoupled systems with event-driven communication patterns, including managing event flow, state and consistency in complex distributed environments.
  • Proven experience building production webhook systems, including signature verification, idempotency and retry logic, so third-party data flows stay fault-tolerant.
  • Proven experience with Entity Framework Core, Dapper, Azure SQL Server and Azure Cosmos DB.
  • Hands-on experience with container-first architecture and Azure services such as Event Hubs, Key Vault, Blob Storage and Managed Identity, plus the ability to manage the infrastructure-as-code deployment lifecycle.
  • Familiarity with APM platforms (Dynatrace, New Relic, Datadog) to diagnose bottlenecks, plus structured logging with Serilog and health check endpoints for service readiness.
  • Experience with defensive coding patterns and libraries like Polly, designing systems for graceful degradation and automatic recovery.
  • Skill with xUnit testing (e.g., Moq or NSubstitute and FluentAssertions). Experience with integration testing via WebApplicationFactory and security scanning tools (e.g., StackHawk, CodeQL) is a plus.
  • A strong appreciation for clean API design, with experience in OpenAPI and code generation tools (TypeSpec or similar) for consistent contracts across services.
  • The ability to explain complex technical trade-offs to non-technical stakeholders clearly, so technical constraints never get in the way of a great user experience.
